# jeu-avanture
Concevoir et développer un jeu d’aventures dans lequel le joueur contrôle un personnage évoluant dans un monde composé de plusieurs salles. Au cours de son exploration, le joueur devra observer son environnement, résoudre des énigmes et affronter éventuellement des monstres. L’objectif final est de découvrir un trésor caché dans un coffre-fort.
